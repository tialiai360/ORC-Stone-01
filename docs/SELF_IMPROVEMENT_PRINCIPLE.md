# ORC Self Improvement Principle

> **SoT (canonical):** [`ORC-Knowledge/Architecture/SELF_IMPROVEMENT_PRINCIPLE.md`](../../ORC-Knowledge/Architecture/SELF_IMPROVEMENT_PRINCIPLE.md)
